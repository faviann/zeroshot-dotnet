Disposable API sketch · one example

Submit a run.
Get its result.

Assume you already have the target configuration and a request containing your prepared graph, runtime and source. This is the ordinary code we’re reviewing.

using Zeroshot;

await using var zeroshot = new ZeroshotClient(options);

var run = await zeroshot.SubmitAsync(request);
var result = await run.WaitAsync();

The client holds the connection options. Creating it does not start a run.

Simulated state: client configured · no submission · no result

Accepted: SubmitAsync → Run → WaitAsync.

The returned run gives you something to inspect now or return to later. This ordinary calling style has been accepted in live review.

One-call convenience

When you only want the final result, the same two steps can be combined:

var result = await zeroshot.RunAsync(request);
